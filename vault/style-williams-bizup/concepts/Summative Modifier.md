# Summative Modifier

**Definition:** A noun-phrase modifier added after a grammatically complete clause that sums up the substance of what came before, usually continued by a restrictive *that* clause.

**Recognize it:** *…less than zero, a demographic event that will have serious social implications.* Contrast the tacked-on *, which will have…*, whose *which* has a vague reference.

**How to build:** end a complete segment with a comma; add a term summing up the sentence so far (*a possibility, a challenge, an achievement*); continue with *that…*.

**Why it matters:** Same closure-then-restart effect as the [[Resumptive Modifier]]; fixes the vague *which* that refers to a whole clause.

**Example:** "American productivity has risen to new heights, an achievement that only a decade ago was considered an impossible dream."
