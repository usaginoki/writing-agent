# Introduction Structure

**Definition:** the default plan for introductions: [Prelude] + **Shared Context** + **Problem (Condition + Cost)** + **Solution / Main Point / Claim**.

**Parts:**
- *Prelude* (optional): quotation, startling fact, or anecdote introducing themes; rare in natural/social sciences, more common in humanities and general-audience writing.
- *Shared context*: what readers know, have experienced, or accept (history, event, belief, literature review); set up to be challenged.
- *Problem*: opens with *but/however*; condition then cost ([[Problem (Condition and Cost)]]).
- *Solution*: action (practical) or claim/answer (conceptual), in the final stress position with key themes.

Reverse the order to get the default [[Patterns - Conclusions]].
