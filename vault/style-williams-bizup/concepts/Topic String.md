# Topic String

**Definition:** the sequence of subjects/topics across the sentences of a passage. A strong string is a narrow set of related, repeated ideas (e.g. *readers, they, they, they, topics, readers, that, they*).

**Recognize it:** underline the first 7-8 words of each sentence ([[Topic string test]]). Random, unrelated openers = weak string = passage feels choppy, unfocused.

**Why it matters:** the topic string is what makes a *passage* [[Coherence|coherent]]. Aim for consistency without mechanical repetition.
