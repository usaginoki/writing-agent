# Theme

**Definition:** a key concept running through a passage, repeated in nouns, verbs, adjectives anywhere (not only subjects). Distinct from [[Topic]] (what a sentence is about, mostly subjects).

**Recognize it:** highlight related words across a paragraph; each cluster is a theme. In the Alzheimer's paragraph: testing (*diagnosis, guess, new tests, predict*), mental states, and *a new problem*.

**Why it matters:** readers connect ideas to a few key concepts, so coherence rises when themes are announced in the stress of the opening sentence and then repeated ([[Thematic Thread]]).
