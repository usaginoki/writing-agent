# Cohesion

**Definition:** the sense that consecutive sentences fit together like jigsaw pieces. Readers judge it from how each sentence ends and the next begins: the last few words of one set up the first few words of the next (p. 69).

**Recognize it:** the sentence start repeats or evokes what the previous sentence ended with. Lack of it feels choppy, in fits and starts.

**Why it matters:** the biggest reason the passive exists. Overall cohesion trumps single-sentence clarity (p. 70). Cohesion is local (pairs); [[Coherence]] is global.

**Note:** cohesive sentences can still be incoherent (Sayner/mashed-potatoes chain, p. 71-72).
