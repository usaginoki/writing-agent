# Agent

**Definition:** The doer or source of an action. In active clauses it is the subject; in passive clauses it appears in a `by` phrase or is dropped.
**Recognize:** `The money was lost [by me]` -> agent `me`.
**Why it matters:** Dropping the agent is fine when unknown, obvious or irrelevant; problematic when readers need to know who is responsible or when a writer hides accountability (`the flaw was uncorrected`).
**Example:** The agent (voters) is self-evident in `The president was reelected`.
