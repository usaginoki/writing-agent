# Patterns - Word distinctions

Careful (if few) readers notice these; use the traditional sense or choose a plain word.

| Word | Means | Not |
|---|---|---|
| aggravate | make worse (injury) | annoy |
| anticipate | prepare for a contingency | merely expect |
| anxious | uneasy | eager |
| blackmail | extort by threatening exposure | coerce |
| cohort | group attending someone | single companion |
| comprise | include all parts (alphabet comprises letters) | constitute |
| continuous / continual | uninterrupted / repeated with breaks | synonyms |
| disinterested | neutral | uninterested |
| enormity | hugely bad | enormous |
| fortuitous | by chance | fortunate |
| fulsome | sickeningly excessive | much |
| notorious | known for bad behavior | famous |
| flaunt / flout | display / scorn a rule | interchangeable |

Expected of any schooled writer: imply/infer, principal/principle, accept/except, capital/capitol, affect/effect, proceed/precede, discrete/discreet. Plurals: datum/data, criterion/criteria, medium/media, stratum/strata, phenomenon/phenomena.
