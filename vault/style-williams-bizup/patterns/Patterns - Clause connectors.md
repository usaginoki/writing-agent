# Patterns - Clause connectors

Use to join character-action clauses after de-nominalizing.

| Relation | Connectors | Template |
|---|---|---|
| Simple cause | because, since, when | X because Y; Since X, Y |
| Conditional | if, provided that, so long as | If X, then Y |
| Contradicting expected cause | though, although, unless | Although X, Y |
| Addition / contrast / result | and, but, so | X and/but/so Y |
| Embedded content | that, how, why, whether | decided *whether* to..., reviewed *how* the brain evolved |

Example: Our loss in sales was the result of their expansion of outlets -> We lost sales **because** they expanded outlets.
