# Patterns - Introductions

Default plan: [Prelude] > Shared context > *But* + Condition > Cost (answer to So what?) > Solution.

## Practical problem
| Part | Template | Example |
|---|---|---|
| Shared context | brief statement you will qualify | "Alcohol has been a part of college life for hundreds of years... drink hard." |
| Condition | *But/However...* + condition, then imagined So what? | "But a kind of drinking known as 'binge' drinking is spreading... to pass out." |
| Cost | palpable consequences to readers | "Bingeing is far from harmless... deaths, injuries, destruction of property." |
| Solution | an action | "...we must try to control its worst costs by educating students..." |

Goal: readers ask "What do we do?" not "So what?".

## Conceptual problem
| Part | Template | Example |
|---|---|---|
| Shared context | what we know | "Colleges report binge drinking is increasing. We know its risks. We also know bingers ignore them." |
| Condition (small question) | *But we don't know...* | "But we don't know what causes bingers to ignore the known risks: social influences, personality, misunderstanding." |
| Cost (larger question) | "If we knew, we might understand ..." | "...we can better understand... the nature of risk-taking behavior in general." |
| Solution | answer that helps the larger question | "In this study, we analyzed... We found that..." |

## Shared-context forms
History; recent event; common belief; literature review (journals).
