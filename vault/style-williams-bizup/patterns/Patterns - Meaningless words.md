# Patterns - Meaningless words

Delete on sight unless deletion changes meaning. Principle: [[Delete meaningless words]].

| tic | tic | tic |
|---|---|---|
| kind of | actually | particular |
| really | certain | various |
| virtually | individual | basically |
| generally | given | practically |

| ✗ | ✓ |
|---|---|
| actually depends on certain factors that basically involve ... any particular technology | depends on psychology more than on technology |
| various technical problems ... did not really affect the election's actual result | technical problems ... did not affect the election's result |

Note: *virtually, generally, practically* can be real [[Hedge]]s; keep if they truly qualify.
