# Patterns - Punctuation choices

Status: R = rule (must), C = common/conventional choice, S = stylistic choice.

## Joining two grammatical sentences (I win ... you lose)
| situation | option | effect | status |
|---|---|---|---|
| default | period: *I win. You lose.* | plain, least noticeable; too many = choppy | C |
| short, closely linked (<15 words) | semicolon | soft period, linked, sophisticated | C |
| ordinary link | comma + and/but/so | conventional; many = simplistic | C |
| important contrasting follow-up | period + *But* | emphasis, will develop | S |
| qualification only | comma + *but* | subordinate weight | C |
| long sentences with commas | period (or semicolon + conj. only if long) | clarity | C |
| both long, internal commas | semicolon | shows grouping | C |
| short close pair | conjunction alone (no comma) | tight link; some teachers object | S |
| very short cause-effect | comma alone | brisk; "comma splice" to many | S |
| explanation/balance | colon | formal, balanced | S |
| afterthought | dash / parentheses | casual / sotto voce | S |
| any pair | nothing | run-on error | R (avoid) |

## Beginnings
| situation | option | effect | status |
|---|---|---|---|
| misparse risk | comma | clarity | R |
| opener ends with semicolon | never | | R |
| subordinating or coordinating conjunction + subject | no comma after the conjunction | | R |
| *Fortunately, However,* | comma | pause | R |
| *Now, thus, hence* | no comma | | C |
| short opener | comma optional (omit = faster) | speed | S |
| long opener (4-5+ words) | comma | breath | R-ish |

## Middles
| situation | option | effect | status |
|---|---|---|---|
| subject-verb / verb-object | no single comma | | R |
| long interruption | paired commas/dashes/parentheses, never semicolons | | R |
| restrictive modifier | no commas | identifies | R |
| nonrestrictive modifier | paired commas | adds info | R |
| comment with internal commas | dashes or parentheses | clear boundaries | S |
| aside / date / gloss | parentheses | quiet | S |
| adverbial position | front / middle / end | shifts stress | S |
| two coordinated items | no comma | | default |
| dramatic contrast / cumulative power | comma (drop *and*) | emphasis | S |
| 3+ items, simple | commas; serial comma consistent | | C |
| 3+ items, internal commas | semicolons | grouping | R-ish |

## Other
| situation | option | note |
|---|---|---|
| plural | no apostrophe (except i's, t's, A's, I's, U's) | R |
| possessive | 's; s-ending: ' only (be consistent) | R |
| contraction | apostrophe; casual in academic | C |
| quotation, period/comma | inside quote marks | R |
| quotation, ? : ; | outside (unless quoted) | R |
