# Patterns - revising sprawl

| Problem | Move | Example (✓ shape) |
|---|---|---|
| Long opening clause | move to end | First-year students should not load up… if they are not certain…, because most change their major… |
| Long opening clause | split / independent clauses | Most undergraduate students change… , so first-year students should not… |
| *Although* opener | drop, add *but/however* | Some writers write well on their own…, but most benefit from instruction… |
| *Since* opener | drop, add *so/therefore* | Few writers write well…, so most first-year college students would benefit… |
| Long subject with nominalization | verb + new subject | Abco Inc. was able to pursue… because it understood what drove profitability… |
| Long subject with relative clause | *when/if* clause → end → own sentence | When a company focuses… / A company is likely… when it… / Some companies focus… Such companies are likely… |
| Interruption S–V | move to front or end | Since some scientists write… , they do not… / …because they write… |
| Interruption V–O | move to front or end | If we are to compete…, we must develop… / We must develop… if we are to compete… |
| Point last | point first | Workers take more responsibility… when they adopt… |
| Relative-clause chain | cut *who/which/that + be*; *that will identify* → *identifying* | …genetic engineering, a new way of manipulating…, the genes and chromosomes that tell our cells… |
| Relative-clause chain | split | Many areas of science are important…, but few are more promising than genetic engineering. It is a new way… |
| Relative-clause chain | modifiers | see [[Patterns - Sentence-extending modifiers]] |
| Relative-clause chain | coordinate | see [[Patterns - Coordination]] |

Mind the periodic-sentence exception ([[Get to the subject of the main clause quickly]]). See [[Do not chain subordinate clauses after the main clause]].
