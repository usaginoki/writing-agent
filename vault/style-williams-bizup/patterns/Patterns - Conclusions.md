# Patterns - Conclusions

Reverse the introduction's parts:

| Step | Move | Example |
|---|---|---|
| 1 | Restate the main claim/solution | "Though we can come at bingeing from several directions, the most important is education... each university must devote time and resources." |
| 2 | Significance: new "So what?" or the cost recast as a benefit | "If we do not control bingeing soon, many more students will die." / "If we start now, we will save many lives." |
| 3 | Further unknown/problem: answer "Now what?" | "Even if we can control bingeing, the larger issue of risk-taking will remain a serious problem." |
| 4 | Coda (optional): echo the prelude | "...after Jim S.'s death... it reported another death this month." |

Use when nothing better comes to mind; conclusions vary more than introductions. Codas: mostly popular writing.
