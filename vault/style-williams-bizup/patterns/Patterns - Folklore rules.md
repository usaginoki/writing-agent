# Patterns - Folklore rules

Status: **real** = enforce; **folklore** = do NOT flag; **optional** = elegant option, formality choice; **hobgoblin** = widely attacked, harmless unless noted.

| Rule | Status | What to do |
|---|---|---|
| Articles precede nouns; verb agrees with subject; pronoun agrees with referent | real | Fix violations |
| Standard vs. nonstandard (*don't have no*) | real (social) | Fix for serious audiences |
| Don't begin a sentence with *and/but* | folklore | Leave; trim only if overused (style) |
| Don't begin with *because* | folklore (in no handbook) | Leave; move new-info clause to end, or use *since* for known info |
| Fragment: *The plan was rejected. Because it was incomplete.* | real | Attach the clause |
| *That* for restrictive, *which* for nonrestrictive | folklore (Fowler 1906) | Leave restrictive *which*; prefer *that* by sound |
| *Fewer* (count) vs. *less* (mass) | folklore for *less* + counts (*no less than five*) | Leave; *fewer dirt* is wrong |
| *since/while* only temporal | folklore | Leave; *since* = known cause, *while* = qualifying concession |
| Don't split infinitives | optional | Leave; unsplit = formal |
| *Whom* as object | optional (real in formal) | Formal: use; else leave *who* in questions; see [[Who-whom deletion test]] |
| Don't end with a preposition | optional | Leave; fix only if the ending is weak |
| *None/any* singular | optional | Leave plural; singular more formal |
| *like* for *as/as if* | hobgoblin | Leave (elision in 18th c.) |
| *hopefully* = I hope | hobgoblin | Leave; parallels *frankly, sadly* |
| *finalize* | hobgoblin | Leave; means "clean up last details" |
| verb *impact* | hobgoblin | Leave; verb for 400 years |
| *very/more perfect, unique, final, complete* | hobgoblin (generally worth following) | Optional avoid; Constitution has *more perfect* |
| *irregardless* | real in practice | Always avoid; use *regardless* |
| Word confusions (*flaunt/flout* etc.) | usage | See [[Patterns - Word distinctions]] |
