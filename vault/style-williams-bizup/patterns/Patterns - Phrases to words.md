# Patterns - Phrases to words

Principle: [[Replace a phrase with a word]]. Many also turn a [[Nominalization]] into a verb.

| wordy phrase | word(s) | book example result |
|---|---|---|
| the reason for | why | explain why the meeting is delayed |
| despite the fact that | even though / although | |
| in the event that | if | If you finish early, contact this office |
| in a situation where | when | When a class closes, you may petition |
| concerning the matter of | about | a few words about money |
| there is a need for ... inspection | must + verb | You must inspect all welds more carefully |
| are in a position to | can | We can make you an offer |
| it is possible that | may | Nothing may come of this |
| prior to the end of | before ... ends | Before training ends, apply |
| a decrease/increase in the number of | fewer / more | fewer/more errors |
| in regard to / in the area of | about / delete | (see [[Patterns - Metadiscourse]]) |
