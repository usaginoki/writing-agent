# Patterns - Old before new

| Problem | Before | After |
|---|---|---|
| New subject follows old ending | ...black holes in space. The collapse of a dead star ... creates a black hole. | ...black holes in space. A black hole is created by the collapse of a dead star... |
| Backward-pointing word late | How to calculate credits ... is another issue we must consider. | Another issue we must consider is how to calculate credits... |
| New info as subject, old as object | The number of dead in the Civil War exceeded all other wars... | Of all the wars in American history, none has exceeded the Civil War in the number of dead. |
| Fronted new info | Only the children of the wealthiest families will be able to afford college if this trend continues. | If this trend continues, college will be affordable only by the children of the wealthiest families. |

Steps: find old item (end of previous sentence) > make it subject (flip with passive/inversion if needed) > put new item at end > check it sets up next sentence.
