# Patterns - Active and passive choice

| Situation | Choose | Example |
|---|---|---|
| Agent unknown/obvious/irrelevant | passive | The president was reelected with 54% of the vote. |
| Long new subject, short familiar object | passive | This decision was supported by research demonstrating... |
| Keep one character as consistent subject | whichever voice keeps it | Allies: active; Germany: passive |
| Metadiscourse verb (argue, define, show) | active, first person | We must define the terms. |
| Research procedure anyone can do | passive | preparations were added |
| Writer should be accountable / reader must know who | active | name the doer |
| Active in form but flat (nominalization + abstract subject) | rewrite with character | Problem management requires cost control -> We can manage the problem if we control costs |
