# Put reference signals at the start of the sentence

**Rule:** Words that point back (*this, these, that, those, another, such, second, more*) go at or near the beginning of the sentence.
**Why (reader effect):** they mark old information, so they belong in the old slot where readers expect the link.

## Diagnose
- Find backward-pointing words buried mid- or late-sentence.

## Revise
1. Restructure so the signal opens the sentence.

## Examples
> ✗ How to calculate credits for classes taken in a community college is another issue that we must consider.
> ✓ Another issue that we must consider is how to calculate credits for classes taken in a community college.

## When not to apply / exceptions
- None stated in source.
