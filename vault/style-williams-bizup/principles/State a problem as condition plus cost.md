# State a problem as condition plus cost

**Rule:** A problem statement needs both parts: a condition that can cause trouble and the intolerable consequence (cost) readers don't want to pay. Put them together before offering a solution.
**Why (reader effect):** readers recognize a problem only when they see condition and cost together; the cost is what motivates them to want a fix.

## Diagnose
- Divide the problem into condition | cost. Is either missing?
- Is the "problem" just a one- or two-word label (*cancer*, *binge drinking*)? Labels name only conditions.

## Revise
1. Write the condition as a plain statement.
2. Add the cost (see [[Find the cost by asking So what]]).
3. Make sure condition type and cost type match (see [[Choose practical or conceptual framing deliberately]]).

## Examples
> ✓ condition: "a kind of drinking known as 'binge' drinking is spreading... Bingers drink quickly... to get drunk or even to pass out."
> ✓ cost: "In the last six months, it has been cited in at least six deaths, many injuries, and considerable destruction of property."
