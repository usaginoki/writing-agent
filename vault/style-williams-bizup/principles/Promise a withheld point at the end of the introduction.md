# Promise a withheld point at the end of the introduction

**Rule:** If you have good reason to save the main point for the conclusion, end the introduction with a sentence that promises the point to come *and* states the main themes.
**Why (reader effect):** readers look at the end of the introduction for the point and themes; a promise plus themes still gives them a framework.

## Diagnose
- Is the point absent from the introduction? Is there at least a promise and theme list?

## Revise
1. Add a final introduction sentence naming the themes and signaling that the claim follows.
2. Deliver the point in the conclusion using the same themes.

## Examples
> ✓ "This study examines how X, Y and Z shape ...; the conclusion argues ..." (schematic; the book gives only the rule)

## When not to apply / exceptions
- Default is to state the point up front; telling it won't bore motivated readers.
