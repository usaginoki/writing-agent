# Order coordinate elements from short to long

**Rule:** In balanced coordination, put the shorter element first and the longer, more complex one last; if needed, add a parallel to the second to lengthen it. (pp. 157-159)
**Why (reader effect):** A long-then-short pair "seems to end too abruptly". Short-to-long is a unifying principle of clear style.

## Diagnose
- Read aloud; does the sentence end abruptly on a short coordinate element?
- Compare the word counts of the coordinated elements.

## Revise
1. Reverse the two elements so the short one comes first.
2. If the last element is still thin, extend it with a parallel structure.

## Examples
> ✗ …the connections between those subjective values that reflect our deepest ethical choices and objective research.
> ✓ …the connections between objective research and those subjective values that reflect our deepest ethical choices and strongest intellectual commitments.

## When not to apply / exceptions
- None stated in source. The unifying short-to-long principle also drives: short subject before long predicate, old (short) before new information, short point before long support, and shorter before longer coordinates (p. 158).
