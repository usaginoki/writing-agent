# Do not enforce folklore rules

**Rule:** Do not "correct" usages that careful writers regularly use: sentence-initial *and/but/because*, restrictive *which*, *less* with countable nouns, *since/while* meaning *because/although*, and the hobgoblins (see [[Patterns - Folklore rules]]).
**Why (reader effect):** Careful readers never notice these; "fixing" them makes prose stiffer, can change meaning (e.g., *since* implies known information), and may wrongly imply an error.

## Diagnose
- Run [[Diagnose whether a rule is real before correcting]]. If the "rule" is in the folklore column of the table, leave the text.

## Revise
1. Leave the text unchanged if the only issue is folklore.
2. If a folklore item coincides with a real stylistic problem (too many *and* openers; clause order), fix it on style grounds, not grammar.
3. If a client/editor insists, comply but note it is optional.

## Examples
> ✓ But, it will be asked, is tact not an individual gift? And if that is so, what guidance can a manual offer ...
> ✓ Since asbestos is dangerous, it should be removed carefully.
> ✓ While we agree on a date, we disagree about the place.

## When not to apply / exceptions
- *Irregardless* (follow the rule even if arbitrary); real fragments (*The plan was rejected. Because it was incomplete.*) are errors.
