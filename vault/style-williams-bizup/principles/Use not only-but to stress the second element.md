# Use not only-but to stress the second element

**Rule:** In a pair, *not only X, but (also) Y* puts extra emphasis on Y, the last element.
**Why (reader effect):** *but* signals the weighty element; Y lands in stress.

## Diagnose
- Two joined elements where the second is the point but reads flat (*X and Y*).

## Revise
1. Recast as *not only X, but also Y*; keep Y at the end.

## Examples
> ✗ We must clarify these issues and develop trust.
> ✓ We must not only clarify these issues, but also develop trust.

## When not to apply / exceptions
- Keep the pair parallel ([[Parallelism]]).
