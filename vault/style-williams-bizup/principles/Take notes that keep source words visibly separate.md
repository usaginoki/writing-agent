# Take notes that keep source words visibly separate

**Rule:** Record bibliographic data the first time you touch a source; copy quotations exactly (every comma); mark quotations and paraphrases unambiguously as others' words so weeks later you cannot mistake them for yours.
**Why (reader effect):** Prominent scholars have been accused of plagiarism after "forgetting" unmarked copied text.

## Diagnose
- Do notes distinguish direct quotation, paraphrase and own thoughts (highlight/underline/font)?
- Is each note tied to author, page, source?

## Revise
1. Books: author, title/subtitle, series, edition/volume, city + publisher, year, pages. Articles: author, title, journal, volume/issue, database, date, pages. Online: add URL and access date.
2. Copy long quotations by photocopy/download.
3. Use one visual code for quotations, another for paraphrase/summary.

## Examples
> ✓ Notes: [QUOTE] "...exact words..." (Author, p. 14) / [PARA] my restatement (Author, p. 14)

## When not to apply / exceptions
- None stated in source.
