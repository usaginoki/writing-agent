# Set off nonrestrictive modifiers with commas

**Rule:** No commas around a restrictive modifier (it uniquely identifies the noun). Paired commas around a nonrestrictive one (added information), a single comma if at sentence end. An appositive is a truncated nonrestrictive clause. Same at the end: comma before a tacked-on clause only if it is not essential to the sentence's meaning.
**Why (reader effect):** Commas change meaning: they tell readers whether the modifier is identification or comment.

## Diagnose
- Delete the modifier: does the noun still identify the same thing? Yes means nonrestrictive, commas.
- Appositive: restore *which is*; if it reads as comment, it takes commas.
- End clauses: is the clause crucial? (*No one should violate the law just because it seems unjust.*)

## Revise
1. Restrictive: remove commas.
2. Nonrestrictive: add paired commas (or dashes/parentheses: [[Use dashes and parentheses for loose commentary]]).
3. At sentence end replace the second comma with the period.

## Examples
> ✓ The house that I live in is 100 years old.
> ✓ We had to reconstruct the larynx, which is the source of voice, with cartilage from the shoulder.
> ✓ I wandered through Europe, seeking a place where I could write undisturbed. / I spent my time seeking a place where...

## When not to apply / exceptions
- "This distinction can be tricky" (p. 221); meaning decides: *Offices will be closed July 2-6, as announced...* (comma) vs *secure all safes as prescribed in the manual* (none).
