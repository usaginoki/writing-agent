# Link the end of one sentence to the start of the next

**Rule:** The last few words of a sentence should set up what the next sentence opens with.
**Why (reader effect):** that handoff produces the sense of flow ([[Cohesion]]).

## Diagnose
- For each adjacent pair: does sentence 2's opening repeat or evoke sentence 1's ending? If sentence 2 opens with something unmentioned, flow breaks.

## Revise
1. Find the key word at the end of sentence 1.
2. Rebuild sentence 2 to start with it (often via passive: [[Use the passive to put old information first]]).
3. Make sentence 2's ending set up sentence 3 likewise.

## Examples
> ✗ ...scientists studying **black holes in space**. The collapse of a dead star into a point no larger than a marble creates a black hole.
> ✓ ...scientists studying black holes in space. A black hole is created by the collapse of a dead star into **a point perhaps no larger than a marble**. So much matter compressed into so little volume changes the fabric of space...

## When not to apply / exceptions
- None stated in source. (Pairwise linking alone does not guarantee [[Coherence]].)
