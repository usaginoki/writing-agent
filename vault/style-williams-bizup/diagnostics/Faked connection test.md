# Faked connection test

**Purpose:** catch conjunctions and transitions that assert logic that is not there.

## Procedure
1. Circle every *thus, therefore, hence, however, also, indeed, moreover, furthermore, another, nevertheless, consequently*.
2. For each, state the actual relation (contrast/qualification for *but/however*; wind-up for *therefore*). Ask a reader to call bluffs (Ex. 5.5).
3. Count: more than a few per page is suspect; *and/also/another* just say "one more thing".

## Signals
- Connectors with no logical link; most likely when you are struggling with the ideas.
