# Diagnose sentence boundaries

**Purpose:** Find run-ons, comma splices, accidental fragments and over-chopped or over-chained prose.

## Procedure
1. Mark every grammatical sentence (main clause + its dependents) with a slash, ignoring existing punctuation (the book's Exercise A.1 method).
2. At each slash, name the signal present: period, semicolon, comma + coordinating conjunction, other.
3. Check each punctuated sentence for a main clause (fragment?).
4. Count short punctuated sentences in a row (choppy) and slashes inside one punctuated sentence (sprawl).
5. Check semicolons: sentence on both sides? After a "however"?

## What signals a problem
- No mark or only a comma between two grammatical sentences (run-on/splice) -> [[Signal the end of every grammatical sentence]].
- "..., however," joining sentences -> [[Use a semicolon only between short linked sentences]].
- A period after a *because/which* clause -> [[Use sentence fragments only on purpose]].
- Many 3+ clause chains -> [[Sprawl]].
