# Noun string test

**Purpose:** Spot lumpy compound noun phrases.

## Procedure
1. Find runs of 3+ nouns where each modifies the next.
2. Are any nominalizations? Is any an invented, non-standard combo?
3. Is any part a technical term in your field? Mark it to keep.

## Signal of a problem
- Run of 3+ nouns with nominalization; relations between nouns are unstated.
