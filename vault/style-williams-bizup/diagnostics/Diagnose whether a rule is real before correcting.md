# Diagnose whether a rule is real before correcting

**Purpose.** Stop an editor from "fixing" non-errors.

**Procedure.**
1. Name the rule being invoked.
2. Is it a **Real Rule** (defines English; native writers rarely break it)? Fix.
3. Is it a **Social Rule** (Standard vs. nonstandard)? Fix for serious audiences.
4. Else it is **invented**. Check [[Patterns - Folklore rules]] for status.
5. Test: do competent, even conservative, writers regularly violate it with readers not noticing? If yes: folklore, leave it.
6. If it is an Elegant Option: decide on formality needed by audience.
7. Hobgoblin: leave, except *irregardless* (avoid) and optionally "absolute + more".
8. If the audience/editor insists, comply as style, and note it is optional.

**Signal of a problem.** Only steps 2-3 yes, or a word in [[Patterns - Word distinctions]] in a high-scrutiny text.

**Fixes with.** [[Do not enforce folklore rules]] · [[Treat elegant options as tone choices]] · [[Observe real and social rules]]
