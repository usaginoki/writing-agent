# Old-new test

**Purpose:** detect new information placed at sentence starts. Writers fail this because their own text seems all old.

## Procedure
1. Have a reader underline every piece of new information in a passage (Ex. 5.4).
2. If beginnings of sentences are underlined, revise.
3. Also check pairs: does the end of sentence n set up the start of n+1?
4. Check general-knowledge old info (*astronomers* in a space passage) counts as old.

## Signals
- Underlines at sentence openings; "comes out of nowhere" feeling; choppy flow.
