# Terseness test

**Purpose:** Detect over-compression.

## Procedure
1. Make graduated cuts of a ~200-word passage: redundancy only, reworded, to the bone (e.g. 150, 100, 50 words).
2. Note what each version gains (speed, shape) and loses (voice, charm, nuance, hedges).
3. Give the version to a reader; ask whether it feels abrupt.

## Signal
- Reader reports abruptness, or the voice has been bleached out ("all gristle and bone"). The writer can't judge this alone.

Fix: back off to the earlier version ([[Be concise, not terse]]). Related: [[Diagnose wordiness]], [[Concision]]
