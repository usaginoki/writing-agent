# Where's the point test

**Purpose:** check that each unit (document, section, paragraph, sentence) states its point where readers look.

## Procedure
1. Draw a line after the short opening segment of the unit.
2. Underline the sentence stating the point.
3. Is it the last sentence of the opening segment, directly before the longer segment?
4. Do the underlined words include the key themes?
5. For a difficult text you are reading: if you don't find it in the section's introduction, look at the end of the section; for the whole document, check the conclusion.

## Signals of a problem
Point at the end of the unit; opening sentences generic (background only); no point sentence; point lacks theme words.

## Fixes
[[Put the point sentence at the end of the opening segment]] · [[Name key themes toward the end of the point sentence]] · [[Open every unit with a short framing segment]]
