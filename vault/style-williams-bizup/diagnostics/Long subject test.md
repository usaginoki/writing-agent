# Long subject test

**Purpose:** Find long, abstract subjects.

**Procedure:**
1. Underline each whole subject ([[Subject (Simple and Whole)]]).
2. Flag any longer than 7-8 words.
3. Check for a [[Nominalization]] or a long relative clause inside.

**Signal:** Long whole subject = revise.

**Fix:** [[Shorten long abstract subjects]].
