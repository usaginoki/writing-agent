# Topic string test

**Purpose:** reveal whether a passage's subjects/topics form a focused set ([[Topic String]]).

## Procedure
1. Underline the first 7-8 words of each sentence, stopping at the verb.
2. If possible, underline the first 5-6 words of each clause.
3. Analyze: do the underlined words form a small set of related ideas, for readers, not just you? Do they name the most important characters, real or abstract?
4. Rewrite: in most sentences make subjects name topics; confirm they are familiar.

## Signals
- Many unrelated or abstract subjects; topics that shift randomly; passage feels choppy, unfocused, disorganized.
