# Sentence length check

**Purpose:** Decide whether sentence length needs deliberate attention.

## Procedure
1. Count words of each sentence in a paragraph or page.
2. Flag if all are below ~15 or all above ~30.
3. Otherwise leave length alone; clarity edits vary it naturally.
4. If flagged, ask whether the effect is intentional (urgency, certainty, mimicry).

## Signals a problem
- Uniform staccato with no purpose; or uniformly long and sprawling.

## Fixes
- [[Vary sentence length only at the extremes]]
