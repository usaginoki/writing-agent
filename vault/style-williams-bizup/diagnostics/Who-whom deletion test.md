# Who-whom deletion test

**Purpose.** Pick *who* or *whom* in a relative clause.

**Procedure.**
1. Confirm the clause modifies a noun (*someone who/whom ...*).
2. Delete the pronoun. If the clause still makes sense: *whom* (*chose someone [ ] they trusted*).
3. If it breaks (*chose someone [ ] earned their trust*): *who*.
4. Exceptions: (a) a clause that is the object of a verb cannot delete *whom*; use the clause's own grammar (*decided whom they should choose* / *who was to be chosen*). (b) Object of a preposition: always *whom* (*in whom they had confidence*).

**Signal.** Wrong form per this test = real error only for formal readers; otherwise an elegant option.
