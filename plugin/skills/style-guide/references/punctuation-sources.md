# Punctuation and sources (research papers)

Punctuation is mostly choice, not rule. Write a well-structured sentence first and the punctuation mostly follows. Do not "fix" a punctuation choice; only fix rules and boundary errors.
Source-use is a rule domain: credit and integrity, not style.

## Joining two grammatical sentences
| Situation | Option | Effect | Status |
|---|---|---|---|
| Default | period | plain; too many = choppy | C |
| Short, closely linked (<15 words) | semicolon | soft period, linked | C |
| Ordinary link | comma + and/but/so | conventional; many = simplistic | C |
| Important contrast | period + `But` | emphasis | S |
| Qualification only | comma + `but` | subordinate weight | C |
| Both long, internal commas | semicolon | shows grouping | C |
| Explanation or balance | colon (after a complete clause) | formal | S/R |
| Afterthought | dash / parentheses | casual / quiet | S |
| Short pair, no mark; or comma alone (very short cause-effect) | | brisk, risky | S |
| Two sentences, nothing or only a comma (splice) | | run-on | R: fix |
`however` / `therefore` joining two sentences takes a semicolon or period, not a comma. [[Use a semicolon only between short linked sentences]] · [[Use a colon only after a complete clause]] · [[Join sentences with a comma and a coordinating conjunction]]

## Middles
| Situation | Option | Status |
|---|---|---|
| Subject-verb or verb-object | NO single comma between | R |
| Long interruption | paired commas / dashes / parentheses (never semicolons) | R |
| Restrictive modifier | no commas | R |
| Nonrestrictive modifier | paired commas | R |
| Comment containing commas | dashes or parentheses | S |
| Two coordinated items | no comma | default |
| Dramatic contrast | comma, drop `and` | S |
| 3+ items, simple | commas; serial comma consistent | C |
| 3+ items with internal commas | semicolons | R-ish |

# Part B: Sources (research papers)

## Core rule
Credit any source whose words or ideas you use. Readers read words, not minds; avoid anything that lets an informed reader think you take credit for another's words or ideas. [[Cite every word and idea you borrow]]
Three kinds:
1. Exact words: quotation marks (or block) + citation with page.
2. Paraphrase: no marks, fully recast, + citation with page.
3. Idea or method: citation (no page if the whole work is the idea).
Applies to online, oral, recorded sources too. Ordinary phrases anyone would use need neither.

## Agent hard rules (editing a draft)
- PRESERVE every citation exactly: author-date tags, numbers, page numbers, footnote markers, URLs, DOIs, bibliography entries. Never reorder, merge, renumber, "tidy" or drop them.
- Keep each citation attached to the claim it supports. When moving, merging or splitting sentences, carry the citation with the content; if a split makes the attachment ambiguous, ask the user.
- Do not add citations, authors, pages, or facts the user did not provide. Insert `[citation needed]` only if asked.
- Never alter text inside quotation marks, including ellipses and brackets; if the quote must change, ask.
- Do not paraphrase a quotation into unmarked text, and do not strip quotation marks to improve flow.
- Do not change citation style (Chicago/MLA/APA); one standard style, applied consistently. [[Use one standard citation style]]
- Never turn the user's paraphrase into a closer-to-source one (synonym swaps).

## Checks
### SR1 Quoting
- Verbatim words have marks or block. Run-in quotes up to four lines; five or more: block (no marks). Never start in running text and finish in a block. [[Format quotations by length]]
- Quote striking words once, at first use, with citation; later reuse is unmarked. Ordinary words: no marks. [[Quote striking words once]]
- Punctuation: period/comma inside closing marks; `?` `:` `;` outside unless part of the quote. [[Punctuate quotations correctly]]
- Changes inside quotes: `[brackets]` for added words, `. . .` for omissions, `[my emphasis]` for added emphasis; never alter meaning.

### SR2 Integration
- State how the quote fits your argument before it appears; weave into your own grammar where possible; trim to key words.
- Signal verb matches your stance (`says` vs `claims` vs `suggests`); comma + capital after `said,`; none after `said that`. [[Introduce each quotation with a signal phrase that fits it]]
- Dropped quote with no lead-in is acceptable but artless. Keep your voice dominant: sources support, they do not replace, your thinking. [[Weave quotations into your own sentences]] · [[Keep your voice dominant]]
- Exception: when exact wording is the object of analysis, longer quotation is fine.

### SR3 Paraphrase and patchwriting detection
Patchwriting = source structure with swapped synonyms, even if cited. Detect:
1. Put sentence and source side by side.
2. Same clause order and sentence skeleton? Mostly the same words with synonyms swapped? Same example sequence? -> too close.
3. Distinctive phrases of the source reused without marks? -> quote them.
4. Fix: state the point from memory in your own structure, with citation; add a signal phrase naming the author.
- ✗ `The theater is a very social genre because it relates so directly with its viewers.`
- ✓ `Levin claims that we experience theater as the most social literary form because we see it unfold before us.`
In a revision task: if the user's text is too close, FLAG it and ask; do not silently rewrite the provenance. [[Paraphrase in a new structure, not with synonyms]]

### SR4 Citation completeness
- Every non-original claim, fact, method, phrase: traceable to a cited source. List any uncited ones for the user; do not invent sources. [[Diagnose plagiarism risk]]
- Citation style and format consistent throughout; reference list matches in-text cites (flag mismatches; do not fix by guessing).
- Notes: keep quotation, paraphrase, and own thought visibly separate. [[Take notes that keep source words visibly separate]]

## Severity (for meaning/integrity pass)
- Block: dropped/altered citation; altered quotation; stripped quote marks; fabricated source.
- Ask user: ambiguous citation attachment after restructuring; paraphrase suspiciously close to source.
- Note: style inconsistencies, signal-verb mismatch, block vs run-in formatting.
