# Correctness and folklore: what NOT to "fix"

**Purpose:** stop false corrections. Correctness is a small, finite job; put it behind you and spend effort on clarity. [[Put correctness behind you and spend effort on clarity]]
Rule of thumb: if competent writers regularly break the "rule" and careful readers never notice, the rule has no force. Changing folklore makes prose stiffer, can change meaning, and wrongly implies the writer erred.

## Before any grammar correction (gate)
1. Name the rule you are invoking.
2. Real rule? Fix. Social (Standard vs. nonstandard) rule in a serious text? Fix.
3. Otherwise it is invented: look it up below.
4. Folklore or hobgoblin: leave the text. Report nothing.
5. Optional/elegant: leave unless the register calls for the formal variant or the user's memory/preferences say so.
6. If a folklore item coincides with a genuine style problem (e.g. ten sentences starting `And`), fix on style grounds and say so; never cite grammar.
7. If the user insists on a folklore rule, comply and note it is optional.

## 1. Real rules (fix)
| Rule | Example fix |
|---|---|
| Subject-verb agreement | `The results was` -> `were` |
| Pronoun-referent number agreement | `efforts failed because it ignored` -> `they ignored` |
| Articles precede nouns; basic word order | `a evidence` -> `the evidence` |
| Real fragment: dependent clause punctuated as sentence | `The plan was rejected. Because it was incomplete.` -> attach the clause: `...rejected because it was incomplete.` |
| Run-on / comma splice between two grammatical sentences | add period, semicolon, or comma + conjunction (see [[Diagnose sentence boundaries]]) |
| Nonstandard forms in serious text: `don't have no`, `ain't`, `irregardless` | `doesn't have any`; `regardless` |
Collective nouns: singular when the group acts as one, plural when members act separately; stay consistent within a sentence.
Vault: [[Observe real and social rules]] · [[Make pronouns agree with their antecedents]]
Exception: dialogue and deliberate register. Errors do not signal low intelligence; do not moralize.

## 2. Usage distinctions (fix only in formal registers or high-scrutiny text)
Few readers notice, but careful ones do. Use the traditional sense or a plainer word. Do not lecture in casual text.
| Word | Traditional sense | Not |
|---|---|---|
| aggravate | make worse | annoy |
| anticipate | prepare for | merely expect |
| anxious | uneasy | eager |
| blackmail | extort by threat of exposure | coerce |
| comprise | include all parts (the whole comprises the parts) | constitute |
| continuous / continual | uninterrupted / repeated with breaks | synonyms |
| disinterested | neutral | uninterested |
| enormity | hugely bad | enormous |
| fortuitous | by chance | fortunate |
| fulsome | sickeningly excessive | plentiful |
| notorious | known for bad | famous |
| flaunt / flout | display / scorn a rule | interchangeable |
Always fix (any register): imply/infer, principal/principle, accept/except, affect/effect, proceed/precede, discrete/discreet, capital/capitol; plurals datum/data, criterion/criteria, medium/media, phenomenon/phenomena.

## 3. Folklore rules (NEVER enforce)
| Folklore | Why leave it |
|---|---|
| No sentence-initial `And` / `But` | Careful writers do it constantly; trim only if overused (style) |
| No sentence-initial `Because` | In no handbook; fine. A `because` clause with new info may read better at the end |
| `That` restrictive / `which` nonrestrictive | Fowler 1906, not usage; restrictive `which` is fine. Nonrestrictive still takes comma + `which`, never `that` |
| `Fewer` vs `less` with counts (`no less than five`) | Not a real rule. (`fewer dirt` is still wrong) |
| `Since` / `while` only temporal | `since` = known cause, `while` = concession; both legitimate, and swapping can change meaning |
| `Like` for `as` / `as if` | Hobgoblin; centuries old |
| `Hopefully` = `I hope` | Parallels `frankly`, `sadly` |
| `Finalize` | Means "clean up last details" |
| `Impact` as verb | In use for ~400 years |
| `More perfect`, `very unique` | Hobgoblin; the Constitution says `more perfect`. Avoiding is optional |
| Rule-of-thumb "no contractions" in everyday text | Register, not grammar |
Exceptions: `irregardless` (avoid, always) and real fragments (see section 1).

## 4. Optional / elegant choices (register decisions, not errors)
Follow the user's stated preference or memory. With none, keep the register of the existing text; do not impose the formal variant.
| Choice | Formal variant | Plain variant | Fix only if |
|---|---|---|---|
| Split infinitive | `to conceal slightly the fact` | `to slightly conceal the fact` | the split itself is awkward |
| Final preposition | `a stick with which to beat` | `a stick to beat the official with` | sentence ends weakly on a light word (see lens-elegance EL1) |
| `Whom` | `The man with whom I met` | `The man I met with` | formal register; test with [[Who-whom deletion test]] |
| `None` + verb | `None is sufficient` | `None are sufficient` | formal register only |
| `That` vs `which` (restrictive) | either | either | `that` is softer; use `which` if two `that`s crowd |
Who/whom rule: delete test: if the clause still works with `whom`/him, use `whom`; after a preposition always `whom`; `Who am I writing for?` is fine informally.
Observing all options all the time earns little and sounds stiff.
Vault: [[Treat elegant options as tone choices]] · [[Use who and whom by the grammar of their own clause]] · [[Who-whom deletion test]] · [[Style as Choice]]

## 5. Generic pronouns policy
No option is perfect. Pick the least-bad for the audience and keep referents clear. Do not "correct" an existing choice unless it causes bias or ambiguity.
| Option | Cost |
|---|---|
| generic `he` | biased; avoid |
| `he or she` | clumsy if repeated; once or twice is fine |
| `s/he`, `he/she` | worse; avoid |
| plural noun + `they` | may blur referents (writers/readers) |
| repeat the singular noun | precise; can be heavy |
| `we` | ambiguous if the group is unclear |
| impersonal abstraction | vague, nominalized |
| alternating `he`/`she` | intrusive to some |
| singular `they` | some call it lazy; widely accepted, likely future standard |
Policy: default to a plural rewrite or singular `they`; if the user or style guide prefers otherwise, follow it. Never rewrite an author's singular `they` into `he or she`, or the reverse, without a reason. Formal conservative audiences may still expect singular agreement.
Vault: [[Handle generic pronouns without bias]] · [[Patterns - Generic pronoun options]] · [[Make pronouns agree with their antecedents]]

## Reporting rule
- Real-rule fixes: apply silently or list as "errors".
- Optional/register items: at most one note ("optional, formal"), never in quick mode.
- Folklore: never mention, except to reassure when the user asks.
